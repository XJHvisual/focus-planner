# 周计划表：课程+锻炼智能合并方案

## 目标
将锻炼计划通过算法插入到课程表的空闲时段中，形成**统一的课程+锻炼视图**，而非上下两个独立区域。

## 核心算法：空闲时段匹配

### 输入
1. **课程数据**：每门课 { day, start, end }
2. **锻炼数据**：每天固定计划 { 周一: { title, duration_min }, 周二: ... }

### 算法流程

```
对于每一天（周一~周日）：

  1. 收集该天所有课程的时间段 → 排序 → day_slots

  2. 计算空闲区间（free_intervals）：
     - 08:00 到第一节课之间
     - 课间间隙
     - 最后一节课到 22:00 之间

  3. 如果该天有锻炼计划：
     duration = 锻炼时长（分钟）

     a. 遍历空闲区间，找第一个满足 duration 的区间
     b. 优先级规则：
        优先度1: 最后一段空闲（傍晚/晚间锻炼） 权重+10
        优先度2: 不拆分锻炼（区间足够容纳完整时长） 权重+5
        优先度3: 区间长度越接近锻炼时长越好（避免浪费大段时间） 权重+2

     c. 在选中区间内放置锻炼块：
        - 若在课后：start = 课程结束 + 30min缓冲
        - 若在课前：end = 课程开始 - 30min缓冲
        - 若独立区间：居中放置

  4. 生成统一的 time_points（课程+锻炼的所有起止点）
  5. 渲染：课程块（蓝绿紫色系）和锻炼块（橙粉色系）在同一网格中共存
```

### 示例

```
周一课程：10:00-11:45 计算机网络, 13:20-14:55 操作系统原理
空闲区间：08:00-10:00, 11:45-13:20, 14:55-22:00
锻炼计划：上肢力量 60min

算法选择：14:55-22:00（最后一段空闲，权重最高）
放置结果：15:25-16:25（14:55 + 30min缓冲开始）
```

## UI 方案

### 视觉效果
- 课程块：保持现有样式（白底彩色边框 + 圆角 + 📚 图标）
- 锻炼块：同网格内，但用**暖色系**区分
  - 背景：#FFF3E0（浅橙）
  - 左边条：#FF9800（橙色）
  - 边框：#FFB74D
  - 图标：🏋️
  - 文字：深橙 #E65100

### 锻炼块内容
- 第一行：🏋️ 锻炼类型（如 "上肢力量"）
- 第二行：时长（如 "60min"）
- 若空间够：副标题简述

### 交互
- 点击锻炼块 → 弹出详细动作表（复用现有 `show_fitness_detail`）
- 点击课程块 → 不可点击（或弹出课程信息）

## 锻炼数据配置

在 `config.py` 或独立 JSON 中定义：

```python
FITNESS_PLAN = {
    0: {"title": "上肢力量训练（胸+肩+三头）", "duration_min": 60},
    1: {"title": "核心 + 有氧", "duration_min": 40},
    3: {"title": "下肢力量训练", "duration_min": 50},
    4: {"title": "背部力量训练", "duration_min": 60},
    5: {"title": "核心 + 有氧", "duration_min": 40},
    6: {"title": "下肢力量训练 + 拉伸", "duration_min": 60},
}
```

## 边界情况处理

| 情况 | 处理 |
|------|------|
| 当天无课无锻炼 | 列留空或显示 "—" |
| 当天有课无锻炼 | 仅显示课程 |
| 当天无课有锻炼 | 仅显示锻炼，放在上午或下午合理时段 |
| 空闲区间都不够长 | 选最长区间，锻炼时长截断标注 "(建议补做)" |
| 多段空闲都合适 | 选最晚的（晚间锻炼优先） |
